# Data provenance

| File | Origin | Real or synthetic | Units | Notes |
|---|---|---|---|---|
| `synthetic_rod.stl` | Generated by `wb_cli gen-samples` (`src/core/samples.cpp`, `generateCylinderStl`) | **Synthetic**, self-created | metres (assumed; STL has no unit field) | Cylinder, axis +x, L = 1 m, R = 0.05 m, 1008 triangles, ASCII STL |
| `synthetic_rod_temperatures.csv` | Generated by `wb_cli gen-samples` (`generateSyntheticRodCsv`) | **SYNTHETIC. NOT an actual ANSYS export.** | x,y,z in metres; temperature in degrees Celsius | 1517 nodes on the same cylinder; T = exact 1-D rod solution (Task C parameters) + 5 C x (r/R)^2 synthetic radial term; range 20 to 193.19 C |

* Both files were created for this project; no third-party or confidential data, no personal data.
* Schema of the CSV (the ANSYS-style export the parser expects): `node_id,x_m,y_m,z_m,temperature_C`.
* Files can be regenerated byte-for-byte: `bin\wb_cli.exe gen-samples --out data`.
* Large stress-test files are generated on demand (`wb_cli gen-large`) and are not shipped.
