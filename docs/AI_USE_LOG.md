## Incorrect or unsuitable AI output found (real defects, found and fixed during the session)
1. **Plot axis tick generator for log axes could loop forever** (infinite loop in the AI-written plot code); fixed.
2. **Launcher health check read the HTTP response with a single `recv`**; headers and body can arrive in separate segments, so readiness could be misjudged; fixed to read until the connection closes.
3. **Integer overflow risk** in the AI-written code path for large inputs; fixed while stress-testing large files. [Candidate: see the commit history for the exact change.]
4. **Chart legend overlapped the plotted data** in the first UI version; caught by reviewing screenshots and fixed.
5. **Environment report printed an empty compiler-flags line** (visible in my own `wb_cli all` output on Windows); fixed, flags now `-std=c++17 -O3 -DNDEBUG`.
6. **`wb_cli all --out results` failed when the folder did not exist** (found by me on Windows); fixed so output folders are created automatically.
7. **Misread test:** an HTTP 413 from a curl upload was first taken to be the server's size limit. It was curl's default form content type (8 KB cap), not the real limit. Re-tested with the UI's content type: 118.7 MiB parsed fine.
