      Temperature (°C)

      1-D rod, steady state

      −d/dx(k A dT/dx) = q A  ·  T(0)=T₀, T(L)=T_L

      Export

      Assumptions

      • Steady state, constant k and A, insulated lateral surface ⇒ 1-D conduction.
      • Two-node linear elements, uniform mesh; consistent load q·A·h/2 per node.
      • Both ends are fixed temperatures (Dirichlet), imposed by moving known values to the right-hand side.
      • Units: m, m², W/(m·K), W/m³, °C.

      Midpoint error uses the FE interpolation (average of the two nodal values) against the exact curve. For this problem nodal values are exact to round-off, so only midpoints reveal the O(h²) discretisation error: emid = q h²/(8k) = 125 h² °C.
